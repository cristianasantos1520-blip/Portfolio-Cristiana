
# Portfólio — Cristiana Bessa

Portfólio pessoal desenvolvido como atividade prática de HTML5, CSS3 e JavaScript. O objetivo é apresentar minha trajetória como estudante de Análise e Desenvolvimento de Sistemas, minhas habilidades em desenvolvimento e alguns projetos acadêmicos e pessoais.

## Tecnologias utilizadas

- HTML5 semântico
- CSS3 (Flexbox, Grid e media queries)
- JavaScript (eventos e manipulação do DOM)
- Git e GitHub

## Projetos apresentados

- **AgroLog:** interface acadêmica para consulta de estoque e solicitação de reposição.
- **Painel de Monitoramento IoT:** protótipo acadêmico de monitoramento com ESP32 e sensor.
- **MediHealth / DataRescue:** atividade acadêmica envolvendo banco de dados e LGPD.
- **Seravie:** aplicativo pessoal de organização de tarefas, em desenvolvimento.

## Como visualizar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.

## Estrutura dos arquivos

- `index.html` — estrutura da página.
- `style.css` — estilos e responsividade.
- `script.js` — interações da página.
- `README.md` — documentação do projeto.
